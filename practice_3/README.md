# Практическая работа №3

**Вариант 22.** Ассемблер и интерпретатор учебной виртуальной машины.

## Язык ассемблера

Одна команда на строку в формате `мнемоника аргумент`. Мнемонику можно
писать в любом регистре. Аргумент задаётся целым десятичным числом или
шестнадцатеричным числом с префиксом `0x`. Пустые строки и комментарии
после `#` пропускаются.

| Команда | A | Аргумент B | Действие |
| --- | ---: | --- | --- |
| `LOAD` | 0 | Константа 0–268435455 | Загрузить константу в аккумулятор |
| `READ` | 11 | Смещение 0–65535 | Загрузить в аккумулятор слово по адресу аккумулятор + B |
| `STORE` | 3 | Адрес 0–65535 | Записать аккумулятор в память по адресу B |
| `BSWAP` | 5 | Адрес 0–65535 | Развернуть байты слова по адресу B и поместить результат в аккумулятор |

## Запуск

Нужен Python 3.9 или новее. Команды выполняются из папки `practice_3`.

```bash
bash run.sh assemble --input examples/control.asm --output control.bin --ir
bash run.sh assemble --input examples/control.asm --output control.bin --test
python3 -B -m unittest discover -s tests -v
```

Ассемблер читает исходник из `--input`, записывает байты в `--output` и
выводит число команд. Флаг `--ir` показывает поля A и B для первого этапа,
а `--test` показывает байты каждой команды. Флаги можно сочетать.
Команда `LOAD` занимает 4 байта, остальные команды занимают по 3 байта.
Байты записываются от младшего к старшему.

## Интерпретатор и память

Интерпретатор читает двоичный файл из `--input` и сохраняет дамп XML в
`--output`. Параметр `--range START END` задаёт первый и последний
адреса слов в дампе. Обе границы включены. Для `READ` сумма аккумулятора
и смещения должна попадать в диапазон адресов 0–65535. Если команда
обрезана, код операции неизвестен или за полем B есть ненулевые биты,
интерпретатор завершает работу с сообщением об ошибке.

```bash
bash run.sh assemble --input examples/copy.asm --output copy.bin
bash run.sh interpret --input copy.bin --output copy.xml --range 100 107
cat copy.xml
```

Память команд и данных хранится в одном `bytearray`. Программа загружается
с нулевого байта. Счётчик команд измеряется в байтах. Команды читаются
прямо из этого массива, пока счётчик не достигнет конца загруженного кода.

Адреса данных измеряются в 32-битных словах. Слово с адресом `i` начинается
с байта `4 * i`. Перед загрузкой кода все 65536 слов заполнены нулями.
Аккумулятор тоже начинается с нуля. Слова хранятся от
младшего байта к старшему. В XML каждое слово записывается как `cell` с
атрибутом `address` и десятичным значением.

В примере данные начинаются со слова 100 (байт 400), а код занимает только
68 байт. Разнос кода и данных по адресам позволяет записывать массивы
без перезаписи команд. Запись в область кода меняет байты, из которых
интерпретатор прочитает следующие команды.

## Проверка bswap()

`BSWAP` читает слово целиком и меняет порядок всех четырёх байтов.
Например, из `0x01020304` получается `0x04030201` (67305985).
Команда `STORE` сохраняет результат из аккумулятора в памяти.

```bash
bash run.sh assemble --input examples/bswap.asm --output bswap.bin
bash run.sh interpret --input bswap.bin --output bswap.xml --range 100 101
cat bswap.xml
```

## Векторы из девяти элементов

Программы `vector_bytes.asm`, `vector_edges.asm` и `vector_small.asm`
заполняют слова 100–108 и сохраняют преобразованные элементы в тех же
словах. Каждая программа состоит из 36 команд.

```bash
for name in vector_bytes vector_edges vector_small; do
  bash run.sh assemble --input "examples/$name.asm" --output "$name.bin"
  bash run.sh interpret --input "$name.bin" --output "$name.xml" --range 100 108
  cat "$name.xml"
done
```
