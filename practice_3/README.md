# Практическая работа №3

**Вариант 22.** Ассемблер и интерпретатор учебной виртуальной машины.

## Язык ассемблера

Одна команда на строку в формате `мнемоника аргумент`. Мнемонику можно
писать в любом регистре. Аргумент задаётся целым десятичным числом или
шестнадцатеричным числом с префиксом `0x`. Пустые строки и комментарии
после `#` пропускаются.

| Команда | A | Аргумент B | Действие |
| --- | ---: | --- | --- |
| `LOAD` | 0 | Константа 0–268435455 | Загрузить константу в аккумулятор |
| `READ` | 11 | Смещение 0–65535 | Прочитать память по адресу аккумулятор + B в аккумулятор |
| `STORE` | 3 | Адрес 0–65535 | Записать аккумулятор в память по адресу B |
| `BSWAP` | 5 | Адрес 0–65535 | Развернуть байты слова по адресу B и поместить результат в аккумулятор |

## Запуск

Нужен Python 3.9 или новее. Команды выполняются из папки `practice_3`.

```bash
bash run.sh assemble --input examples/control.asm --output control.bin --test
python3 -B -m unittest discover -s tests -v
```

На первом этапе ассемблер показывает поля A и B. Путь `--output` принят
как параметр для следующего этапа.
