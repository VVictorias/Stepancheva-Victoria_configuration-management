# Практическая работа №2, вариант 22

Первый этап инструмента визуализации зависимостей Java Maven:
«Минимальный прототип с конфигурацией».
Программа принимает параметры командной строки, проверяет их и выводит
четыре строки `ключ=значение`. Зависимости не загружаются, граф и дерево
не строятся. Флаг ASCII-дерева пока только сохраняется в конфигурации.

Требуется Python 3.9 или новее. Используется только стандартная библиотека.
Установка Maven и дополнительных пакетов не нужна.

## Структура

- `src/cli.py` — аргументы, проверка значений и вывод конфигурации.
- `tests/test_cli.py` — автоматические положительные и отрицательные проверки.
- `tests/fixtures/repository.txt` — локальный файл для проверки тестового режима.
- `tests/RESULTS.md` — фактические команды и результаты проверки.
- `run.sh` — запуск программы.
- `stage_1.md` — отчёт по первому этапу.
- `.gitignore` — исключение служебных файлов Python и сборки.

Файлы эмулятора в корневых `src/` и `tests/` относятся к другой работе.

## Параметры

| Опция | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `--package NAME` | Имя пакета | Обязательный параметр |
| `--repository SOURCE` | URL или путь к тестовому файлу | Обязательный параметр |
| `--test-repository` | Выбрать локальный тестовый источник | `false` |
| `--ascii-tree` | Включить настройку ASCII-дерева | `false` |

Для обычного режима принят формат `groupId:artifactId[:version]`,
например `org.apache.commons:commons-lang3:3.12.0`.
Версия необязательна: на первом этапе пакет не запрашивается.
Части координат непустые, без пробелов; допускаются латинские буквы,
цифры, `_`, `-` и точки; сегменты groupId разделены точками.
В тестовом режиме имя — одна большая латинская буква `A`–`Z`
по описанию тестового репозитория на странице 72 методички.

Обычный источник — абсолютный HTTP(S) URL с корректными сервером и портом.
Данные авторизации, query, fragment, пробелы и повреждённые `%`-последовательности
не поддерживаются. DNS и доступность сервера не проверяются: сетевых запросов нет.
Тестовый источник — существующий обычный файл, доступный для чтения.
Путь может быть абсолютным, относительным или начинаться с `~`.
Относительный путь считается от текущего каталога запуска.
Проверка не читает и не разбирает содержимое файла.
Расширение и формат содержимого на этом этапе не ограничены.

Флаги задаются без значений. Записи `--ascii-tree=false`,
`--test-repository true`, сокращённые и неизвестные опции отклоняются.
Ошибка выводится в stderr с кодом завершения `2`, успешный запуск — `0`.
При ошибке настройки в stdout не печатаются.

## Запуск из корня репозитория

```sh
sh practice_2/run.sh --help
sh practice_2/run.sh \
  --package org.apache.commons:commons-lang3:3.12.0 \
  --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

```text
package=org.apache.commons:commons-lang3:3.12.0
repository=https://repo.maven.apache.org/maven2/
test_repository=false
ascii_tree=true
```

```sh
sh practice_2/run.sh --package A \
  --repository practice_2/tests/fixtures/repository.txt --test-repository
python3 -m unittest discover -s practice_2/tests -v
```

Можно запускать `python3 practice_2/src/cli.py` с теми же аргументами.
Скрипт запуска находит исходный файл независимо от текущего каталога.

общие правила оформления репозитория — страницы 5–6.
