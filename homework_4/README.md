# Домашняя работа №4

**Вариант №22. Ассемблер и интерпретатор учебной виртуальной машины.**

Ассемблер переводит текст программы в машинный код. Интерпретатор выполняет
этот код и сохраняет выбранные слова памяти в XML.
[Отчёт с результатами пяти этапов](../homework_4.md).

## Язык ассемблера

На каждой строке записывается одна команда в виде `мнемоника аргумент`.
Регистр букв в мнемонике не важен. Аргумент задаётся десятичным целым
числом или шестнадцатеричным с префиксом `0x`. Пустые строки и текст
после `#` пропускаются.

| Команда | Код A | Аргумент B | Действие |
| --- | ---: | --- | --- |
| `LOAD` | 0 | Константа 0–268435455 | Записывает константу в аккумулятор |
| `READ` | 11 | Смещение 0–65535 | Читает слово по адресу `аккумулятор + B` в аккумулятор |
| `STORE` | 3 | Адрес 0–65535 | Записывает аккумулятор в слово по адресу B |
| `BSWAP` | 5 | Адрес 0–65535 | Меняет порядок четырёх байтов слова по адресу B и кладёт результат в аккумулятор |

Команды и данные хранятся в одном массиве байтов. Аккумулятор и
незанятые слова памяти изначально нулевые. Адрес данных указан в
32-битных словах. Слова беззнаковые, от младшего байта к старшему.
Для `READ` итоговый адрес должен быть от 0 до 65535.

## Запуск

Нужны Bash и Python 3.9 или новее. Сборка и дополнительные библиотеки
не требуются. Команды выполняются из папки `homework_4`.

- `assemble` читает исходник из `--input`, пишет двоичный файл в `--output`
  и выводит число команд. `--ir` показывает поля A и B, `--test` показывает байты.
- `interpret` читает двоичный файл из `--input` и сохраняет XML в `--output`.
  Параметр `--range START END` задаёт диапазон адресов с обеими границами включительно.
- `--help` показывает параметры выбранной команды.

Пути `--input` и `--output` обязательны. Каталог для выходного файла
должен существовать.

Проверка байтов контрольного примера и копирование массива.

```bash
bash run.sh assemble --input examples/control.asm --output /tmp/control.bin --test
bash run.sh assemble --input examples/copy.asm --output /tmp/copy.bin
bash run.sh interpret --input /tmp/copy.bin --output /tmp/copy.xml --range 100 107
cat /tmp/copy.xml
```

приведены команды и дампы трёх программ с `BSWAP`.
