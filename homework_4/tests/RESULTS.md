# Результаты тестирования

Запуск из папки `homework_4`.

```bash
python3 -B -m unittest discover -s tests -v
```

**Итог.** 25 из 25 тестов прошли.

- Контрольные байты совпали с методичкой. `50 0C 00 00`, `DB 05 00`,
  `F3 3B 00`, `E5 28 00`.
- Копия массива в словах 104–107 совпала с исходным массивом в словах 100–103.
- `bswap(0x01020304)` дал `0x04030201`, `bswap(0x00000080)` дал
  `0x80000000`. Ноль, `0x0A0A0A0A` и `0xFFFFFFFF` сохранили значение.
- Во всех трёх векторах 27 результатов совпали с ожидаемыми по адресам 100–108.
