# Домашняя работа №3

**Вариант 22.** Перевод учебного конфигурационного языка в TOML.

## Постановка задачи

Нужно написать программу, которая читает конфигурацию из файла и
сохраняет её в TOML. Пути передаются через `--input` и `--output`.
Вариант описан на страницах 48–49 файла `конф3.pdf`.

Я написала программу на Python. Команды запуска и установки зависимостей
приведены в [README](homework_3/README.md).

## Разбор конфигурации

Для синтаксического разбора я использовала Lark. В файле
`homework_3/src/language.lark` описаны числа со знаком, строки с префиксом
`@`, массивы `list(...)` и имена из латинских букв и подчёркиваний.
Из этих правил Lark строит дерево разбора.

Правило `declaration` задаёт объявление константы. В правиле `array` каждый
элемент снова разбирается как `value`, поэтому массивы могут быть вложенными.

```lark
declaration: value _WS? "->" _WS? NAME

?value: NUMBER -> number
      | STRING -> string
      | array
      | expression

array: _LIST _WS? "(" _WS? [value _WS? ("," _WS? value _WS?)*] ")"
```

При ошибке разбора программа указывает строку и столбец. Для записи
`list(1, ) -> items` получено сообщение:

```text
Ошибка: bad.cfg: строка 1, столбец 9: синтаксическая ошибка (неожиданный символ ')')
```

## Вычисление констант и запись TOML

Класс `Calculate` проходит по дереву разбора, вычисляет значения и
сохраняет объявления в словаре. Ссылка внутри выражения берёт значение,
которое уже записано в словарь. Повторное объявление и неизвестное имя
вызывают ошибку.

Например, для вычисления `ord` я проверяю тип аргумента и длину строки,
затем вызываю встроенную функцию Python.

```python
def char_code(self, value):
    """Получить код Unicode одного символа."""
    if not isinstance(value, str) or len(value) != 1:
        raise ValueError("для ord нужна строка из одного символа")
    return ord(value)
```

Сложение и вычитание принимают два целых числа. Результат выражения можно
сразу записать в константу или использовать как элемент массива.
Готовый словарь передаётся в `tomli_w.dumps`. Библиотека оформляет ключи,
строки и массивы в формате TOML.

## Примеры работы

Команды выполняются из папки `homework_3` в активированном окружении.

```bash
demo="$(mktemp -d)"
for name in study store classroom; do
  bash run.sh --input "examples/$name.cfg" --output "$demo/$name.toml"
done
```

### 1. Учебное приложение

К пяти основным темам добавлены две дополнительные. Программа вычислила
`total_topics` и сохранила список видов занятий.
[Исходная конфигурация](homework_3/examples/study.cfg) ·
[Полученный TOML](homework_3/examples/study.toml).

```toml
topics = 5
total_topics = 7
```

### 2. Интернет-магазин

Из цены 1290 вычтена скидка 200. Категория `A` преобразована в код 65
через `ord`.
[Исходная конфигурация](homework_3/examples/store.cfg) ·
[Полученный TOML](homework_3/examples/store.toml).

```toml
final_price = 1090
category = "A"
category_code = 65
```

### 3. Компьютерный класс

Два ряда компьютеров описаны вложенным массивом. Номер последнего места
во втором ряду вычисляется выражением `?{+ 5 1}`.
[Исходная конфигурация](homework_3/examples/classroom.cfg) ·
[Полученный TOML](homework_3/examples/classroom.toml).

```text
list(list(1, 2, 3), list(4, 5, ?{+ 5 1})) -> rows
```

После чтения TOML получен массив `[[1, 2, 3], [4, 5, 6]]`.
