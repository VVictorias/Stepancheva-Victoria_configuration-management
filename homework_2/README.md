## Этап 1. Минимальный прототип с конфигурацией

Инструмент визуализации графа зависимостей Java Maven.
На первом этапе программа принимает, проверяет и выводит четыре настройки.

Ход выполнения, ключевой код и примеры результатов приведены
в [отчёте по домашней работе №2](../homework_2.md).

### Запуск программы

Требуется Python 3.9 или новее. Используется стандартная библиотека Python.
Команды выполняются в каталоге `homework_2`:

```bash
bash run.sh --package junit:junit:4.13.2 --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

Результат:

```text
package=junit:junit:4.13.2
repository=https://repo.maven.apache.org/maven2/
test_repository=false
ascii_tree=true
```

Запуск с локальным тестовым файлом:

```bash
bash run.sh --package A --repository examples/repository.txt --test-repository
```

Справка и автоматические проверки:

```bash
bash run.sh --help
python3 -B -m unittest discover -s tests -v
```

### Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `--package ИМЯ` | Обязательные координаты Maven `groupId:artifactId[:version]`; в тестовом режиме — буква A–Z. |
| `--repository ИСТОЧНИК` | Обязательный HTTP(S) URL или путь к файлу при включённом тестовом режиме. |
| `--test-repository` | Включает тестовый режим; по умолчанию выключен. |
| `--ascii-tree` | Включает настройку ASCII-дерева; по умолчанию выключен. |

Флаги задаются без значений. Неизвестные опции и их сокращения отклоняются.
Ошибки выводятся в stderr с кодом 2, успешный запуск возвращает 0.

В координатах Maven допускаются латинские буквы, цифры, `_`, `-` и точки.
Части координат непустые, сегменты groupId разделены точками.
У URL проверяются сервер, порт и экранирование; авторизация, query
и fragment не поддерживаются. Сетевые запросы не выполняются.
Локальный источник должен быть обычным файлом, доступным для чтения.
Поддерживаются абсолютные и относительные пути, а также `~`.
Относительный путь отсчитывается от текущего каталога запуска.
Содержимое и расширение файла на первом этапе не проверяются.

### Файлы работы

- `src/main.py` — точка входа.
- `src/depgraph/config.py` — разбор и проверка аргументов.
- `src/depgraph/cli.py` — вывод конфигурации.
- `examples/repository.txt` — тестовый источник.
- `tests/test_cli.py` — автоматические проверки.
- [tests/RESULTS.md](tests/RESULTS.md) — фактический протокол запусков.
- `run.sh` — скрипт запуска.
- `.gitignore` — исключение служебных файлов.
