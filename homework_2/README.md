## Подготовка и запуск

Нужен Python 3.9 или новее. Сборка и установка Python-пакетов не нужны.
Получение зависимостей использует только стандартную библиотеку.
Для изображения нужен браузер с JavaScript и доступом к CDN Mermaid.
POM загружается из указанного HTTP(S) репозитория с проверкой TLS.

Команды выполняются из каталога `homework_2`:

```bash
bash run.sh --package junit:junit:4.13.2 \
  --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

Программа выводит Mermaid, ASCII-дерево и путь к HTML-странице.
HTML автоматически открывается в браузере и строит SVG-изображение.
Если браузер не удалось запустить, нужно открыть выведенный HTML вручную.
Загрузка JavaScript проверяется на странице, ошибка показывается явно.

Локальный пример с циклом:

```bash
bash run.sh --package A --repository examples/cycle.txt \
  --test-repository --ascii-tree
```

Запуск без открытия браузера с сохранением в выбранный каталог:

```bash
bash run.sh --package A --repository examples/diamond.txt \
  --test-repository --ascii-tree --no-open --output output/diamond
```

По умолчанию файлы создаются в отдельном временном каталоге системы.
При `--output` записываются `graph.mmd` и `graph.html` указанного каталога;
при повторном запуске в тот же каталог эти два файла обновляются.
Генерируемые файлы не нужны в Git.

## Настройки

| Параметр | Назначение |
| --- | --- |
| `--package ИМЯ` | Координаты `groupId:artifactId[:version]`; в тестовом режиме буква A-Z. |
| `--repository ИСТОЧНИК` | HTTP(S) URL или путь к UTF-8 файлу при `--test-repository`. |
| `--test-repository` | Включить локальный источник вместо сетевого. |
| `--ascii-tree` | Дополнительно вывести ASCII-дерево в режиме визуализации. |
| `--mode РЕЖИМ` | `config`, `direct`, `graph`, `order`, `visualize`. По умолчанию `visualize`. |
| `--output КАТАЛОГ` | Каталог для Mermaid и HTML в режиме визуализации. |
| `--no-open` | Не открывать браузер, сохранить представления в файлы. |
| `--help` | Справка без обязательных параметров. |

`--package` и `--repository` обязательны. Флаги передаются без значений.
Сокращения и неизвестные опции не принимаются. Код 0 означает успех,
код 2 означает ошибку аргументов, код 1 означает ошибку загрузки или операции.
При цикле граф и изображение доступны, а топологический порядок невозможен.

Режимы соответствуют этапам работы:

```bash
bash run.sh --package A --repository examples/repository.txt \
  --test-repository --mode config
bash run.sh --package junit:junit:4.13.2 \
  --repository https://repo.maven.apache.org/maven2/ --mode direct
bash run.sh --package A --repository examples/diamond.txt \
  --test-repository --mode graph
bash run.sh --package A --repository examples/diamond.txt \
  --test-repository --mode order
```

`config` выводит четыре исходные настройки первого этапа.
`direct` выводит все прямые объявления POM, включая test и optional.
`graph` выводит список смежности runtime-графа потребителя библиотеки.
`order` выводит зависимости перед потребителями, без анализируемого корня.
`visualize` формирует Mermaid и HTML, открывает изображение в браузере.
Опции ASCII, output и no-open относятся к `visualize`.

## Формат тестового репозитория

```text
A: B C
B: D
C: D
D:
```

Каждая вершина объявляется ровно один раз. Пустой список означает лист.
Допускаются пустые строки и комментарии после `#`, повторы рёбер убираются.
Необъявленные соседи и неправильные имена отклоняются.
Относительные пути считаются от текущего каталога запуска, поддерживается `~`.

В `examples` находятся цепочка, ромб с недостижимой вершиной Z, цикл,
петля и граф из одного листа. Обход показывает только достижимые вершины.

## Реализация и границы

POM разбирается через `xml.etree.ElementTree`. Поддержаны пространства имён,
parent, вложенные свойства, dependencyManagement, импорт BOM и кеширование.
Если версия корня опущена, берётся release из `maven-metadata.xml`.

Для графа оставлены compile/runtime, исключены test/provided/system и optional.
Exclusions, включая `*`, передаются по пути обхода. Это граф зависимостей
библиотеки для потребителя, а не зависимостей тестов самой библиотеки.
Несколько версий одного артефакта сохраняются отдельными вершинами.
Медиация версий по правилу nearest-wins, активируемые профили, диапазоны
версий и timestamped SNAPSHOT не реализованы. Диапазон или неизвестное
свойство вызывают ошибку; программа не подменяет их выдуманной версией.
Встроенные в POM дополнительные репозитории не подключаются.
Для трёх проверенных пакетов runtime-рёбра совпали с Maven.

| Файл | Основные функции |
| --- | --- |
| `src/main.py` | Точка входа. |
| `src/depgraph/config.py` | Аргументы CLI и отдельные проверки имени, URL, файла. |
| `src/depgraph/model.py` | XML, подстановка свойств, структуры POM и зависимости. |
| `src/depgraph/maven.py` | HTTP, metadata, родительские POM, управление зависимостями. |
| `src/depgraph/repository.py` | Текстовый источник и выбор рёбер runtime-графа. |
| `src/depgraph/graph.py` | `build_graph`, `traverse`, `dependency_order`, список смежности. |
| `src/depgraph/visualize.py` | `mermaid_text`, `ascii_tree`, `write_visualization`. |
| `src/depgraph/cli.py` | Выбор операции, вывод и обработка ошибок. |

DFS построения графа, поиск циклов, порядок и ASCII-дерево не используют
рекурсию. Рекурсивно разрешается только наследование моделей POM/BOM,
с отдельным ограничением глубины и защитой от циклов.

## Проверки

```bash
python3 -B -m unittest discover -s tests -v
sh -n run.sh
```

44 теста проверяют CLI, XML, parent, свойства, BOM, DFS, циклы, exclusions,
порядок, Mermaid, ASCII и HTTP на локальном тестовом сервере.
Сеть Internet и установленный Maven для запуска тестов не требуются.
Реальные запросы к Maven Central и сравнение с Maven выполнялись отдельно.
Команды и результаты находятся в [протоколе](tests/RESULTS.md).

Документация оформлена через docstring. Предел строк Python равен 80,
функций 40 строк, цикломатической сложности 10. Новые коммиты имеют
формат Conventional Commits со scope. Старые названия в опубликованной
истории не менялись, поэтому историческое замечание C6 остаётся.
