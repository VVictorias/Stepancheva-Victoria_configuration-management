# Домашняя работа №2

**Вариант 22.** Граф зависимостей Java Maven.

Программа читает POM из Maven-репозитория, строит граф стековым DFS,
проверяет циклы и показывает порядок зависимостей. Визуализация сохраняет
Mermaid и открывает граф в браузере. Команды и результаты пяти этапов
приведены в [отчёте](../homework_2.md).

## Запуск

Нужен Python 3.9 или новее. Сборка и установка библиотек Python не
требуются. Запустите команду из каталога `homework_2`.

```bash
bash run.sh --package junit:junit:4.13.2 \
  --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

| Параметр | Назначение |
| --- | --- |
| `--package` | Координаты `groupId:artifactId[:version]` или буква A–Z в тестовом режиме. |
| `--repository` | HTTP(S) URL репозитория или путь к файлу. |
| `--test-repository` | Прочитать локальный тестовый файл. |
| `--ascii-tree` | Добавить текстовое дерево в режиме визуализации. |
| `--mode` | Выбрать операцию из списка ниже. |
| `--output` | Каталог для `graph.mmd` и `graph.html`. По умолчанию используется временный каталог. |
| `--no-open` | Сохранить диаграмму без открытия браузера. |
| `--help` | Показать справку. |

Режимы работы описаны ниже.

- `config` показывает четыре настройки первого этапа.
- `direct` выводит прямые объявления POM, включая тестовые.
- `graph` печатает список смежности и сообщает о циклах.
- `order` выводит порядок загрузки без корневого пакета.
- `visualize` сохраняет Mermaid и HTML. Этот режим включён по умолчанию.

При неверных параметрах программа возвращает код 2, при ошибке выполнения
код 1. При цикле можно показать граф, а режим `order` сообщит об ошибке.
Браузер загружает Mermaid с CDN для отображения HTML.

## Тестовый репозиторий

Формат строки `A: B C` означает, что пакет A зависит от B и C. Все
вершины объявляются в файле. Строка `D:` обозначает вершину без
зависимостей. Примеры цепочки, ромба и циклов находятся в `examples`.

```bash
bash run.sh --package A --repository examples/diamond.txt \
  --test-repository --mode order
python3 -B -m unittest discover -s tests -v
```

15 тестов проверяют CLI, HTTP, POM, построение графа и визуализацию.
Для тестов достаточно Python и доступа к локальному интерфейсу.

## Обработка Maven

Поддерживаются родительский POM, свойства, `dependencyManagement` и
импорт BOM. Если версия пакета пропущена, программа читает
`release` из `maven-metadata.xml`. Граф потребителя включает
зависимости `compile` и `runtime` с учётом `optional` и `exclusions`.

Разные версии артефакта считаются отдельными вершинами. На более сложных
графах результат Maven может отличаться из-за выбора ближайшей версии,
профилей, диапазонов версий, timestamped SNAPSHOT или дополнительных
репозиториев из POM.
