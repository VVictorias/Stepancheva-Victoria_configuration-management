# Домашняя работа №2

**Вариант:** №22

Программа получает зависимости Java Maven из POM-файлов, строит граф
алгоритмом DFS без рекурсии, определяет порядок загрузки и формирует
Mermaid-диаграмму и ASCII-дерево.
Ход работы приведён в [отчёте](../homework_2.md).

## Функции программы

| Модуль | Назначение |
| --- | --- |
| `config.py` | Разбор аргументов, проверка имени пакета, URL и пути к файлу. |
| `maven.py` | Загрузка POM, metadata, родительских моделей и BOM. |
| `model.py` | Разбор XML, подстановка свойств, описание зависимостей. |
| `repository.py` | Чтение тестового графа, отбор Maven-зависимостей и exclusions. |
| `graph.py` | Построение графа, поиск циклов и порядок загрузки. |
| `visualize.py` | Формирование Mermaid, ASCII-дерева и HTML. |
| `cli.py` | Выполнение выбранной операции и обработка ошибок. |

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--package` | Обязательные координаты `groupId:artifactId[:version]` или буква A-Z в тестовом режиме. |
| `--repository` | Обязательный HTTP(S) URL или путь к тестовому файлу. |
| `--test-repository` | Использовать локальное описание графа. |
| `--ascii-tree` | Вывести ASCII-дерево при визуализации. |
| `--mode` | Выбрать операцию: `config`, `direct`, `graph`, `order`, `visualize`. |
| `--output` | Каталог для `graph.mmd` и `graph.html`. |
| `--no-open` | Сохранить представления без открытия браузера. |
| `--help` | Вывести справку. |

Режим `config` выводит четыре настройки первого этапа, `direct` прямые
объявления POM, `graph` список смежности, `order` порядок зависимостей
без корневого пакета. Режим `visualize` формирует диаграмму и применяется
при отсутствии `--mode`. Флаги передаются без значений.

Код завершения 0 означает успех, 2 ошибку аргументов, 1 ошибку операции.
При цикле можно построить граф, но нельзя получить порядок загрузки.

## Пример использования

Программа написана на Python 3.9 или новее, отдельная сборка не требуется.
Зависимости Python устанавливать не нужно.
Команда из каталога `homework_2`:

```bash
bash run.sh --package junit:junit:4.13.2 \
  --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

Будут выведены Mermaid и ASCII-дерево, создана и открыта HTML-страница.
Для построения изображения браузеру нужен доступ к CDN Mermaid.
Без `--output` файлы сохраняются во временный каталог.
В указанном каталоге файлы `graph.mmd` и `graph.html` при повторном запуске
перезаписываются. Опции `--output`, `--no-open` и `--ascii-tree`
используются в режиме визуализации.

## Тестовый репозиторий

Формат файла:

```text
A: B C
B: D
C: D
D:
```

Все вершины объявляются явно. Пустой список означает лист.
Допускаются пустые строки и комментарии после `#`.
Из выбранного корня обходятся только достижимые вершины.
Примеры цепочки, ромба, цикла, петли и листа находятся в `examples`.

## Особенности обработки Maven

Поддержаны parent, свойства, dependencyManagement и импорт BOM.
Если версия не указана, используется release из metadata.
Прямые объявления выводятся со всеми областями действия.
В граф потребителя включаются compile/runtime, исключаются
test/provided/system и optional. Exclusions учитываются по пути обхода.

Разные точные версии артефакта сохраняются отдельными вершинами.
Выбор версии по nearest-wins, профили, диапазоны версий и timestamped
SNAPSHOT не реализованы. Дополнительные репозитории из POM не подключаются.
