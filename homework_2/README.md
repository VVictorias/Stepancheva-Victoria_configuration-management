# Домашняя работа №2

**Вариант 22. Граф зависимостей Java Maven.**

Программа читает зависимости из POM, строит граф обходом в глубину
(DFS) без рекурсии и находит циклы. Граф можно посмотреть в браузере
или в виде ASCII-дерева в терминале.
[Отчёт с командами и результатами](../homework_2.md).

## Запуск

Для программы нужен Python 3.9 или новее. Дополнительные библиотеки
Python не нужны. Для графического вывода браузер загружает Mermaid из
интернета. Maven нужен только для сравнения результатов.

Примеры запускаются из папки `homework_2`.

```bash
cd homework_2
```

В примере строится граф зависимостей JUnit.

```bash
bash run.sh --package junit:junit:4.13.2 \
  --repository https://repo.maven.apache.org/maven2/ --ascii-tree
```

| Параметр | Назначение |
| --- | --- |
| `--package` | Имя пакета `groupId:artifactId[:version]` или буква A–Z для тестового файла. |
| `--repository` | Адрес HTTP(S) или путь к тестовому файлу. |
| `--test-repository` | Чтение графа из файла. |
| `--ascii-tree` | Вывод дерева в терминале при визуализации. |
| `--mode` | Выбор режима работы. По умолчанию `visualize`. |
| `--output` | Папка для `graph.mmd` и `graph.html`. По умолчанию используется временная папка. |
| `--no-open` | Сохранение файлов без открытия браузера. |
| `--help` | Справка по параметрам. |

- `config` показывает четыре настройки первого этапа.
- `direct` показывает прямые зависимости из POM, включая тестовые.
- `graph` выводит связи между пакетами и сообщает о циклах.
- `order` показывает порядок обхода зависимостей без начального пакета.
- `visualize` создаёт файлы Mermaid и HTML.

Неверные параметры дают код 2, ошибка при работе программы даёт код 1.
При цикле режим `graph` показывает связи, а `order` сообщает об ошибке.

## Файлы

Программа состоит из скрипта запуска и модулей в `src/depgraph`.

- `run.sh` запускает программу.
- `config.py` проверяет параметры, а `cli.py` запускает выбранный режим.
- `maven.py` загружает POM, а `model.py` разбирает их содержимое.
- `repository.py` читает тестовые файлы, а `graph.py` строит граф и ищет циклы.
- `visualize.py` создаёт Mermaid, HTML и ASCII-дерево.
- В `examples` лежат тестовые графы. Папка `examples/maven` содержит POM для сравнения.

Строка `A: B C` в тестовом файле означает, что A зависит от B и C.
Строка `D:` обозначает пакет без зависимостей. Все пакеты должны быть
описаны в файле.

```bash
bash run.sh --package A --repository examples/diamond.txt --test-repository --mode order
```

## Тестирование

```bash
python3 -B -m unittest discover -s tests -v
```

15 тестов проверяют параметры, чтение POM, графы, порядок обхода и
визуализацию. Для проверки загрузки POM используется локальный HTTP-сервер.

## Обработка Maven

Программа читает родительские POM и управляемые версии, в том числе из
POM со списком версий (BOM). Если версия в `--package` пропущена,
программа берёт `release` из `maven-metadata.xml`. Граф учитывает
зависимости `compile` и `runtime`. Тестовые и необязательные
зависимости пропускаются, исключения учитываются при обходе.

Разные версии пакета остаются отдельными вершинами. Программа
не выбирает ближайшую версию и не обрабатывает профили, диапазоны
версий, SNAPSHOT с меткой времени и дополнительные репозитории из POM.
