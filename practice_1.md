## Задача №3
Написать программу banner средствами bash для вывода текстов. Перед отправкой решения проверьте его в ShellCheck на предупреждения.
### Ход выполнения задачи №3
Для выполнения задачи был создан скрипт `banner`:
```bash
#!/bin/bash
# Получение текста и формирование рамки в соответствии с его длиной
text="$1"
length=${#text}
line=$(printf '%*s' "$((length + 2))" '' | tr ' ' '-')
printf '+%s+\n' "$line"
printf '| %s |\n' "$text"
printf '+%s+\n' "$line"
```
Для предоставления файлу права на выполнение была использована команда:
```bash
chmod +x banner
```
Для запуска скрипта была использована команда:
```bash
./banner "Hello from RTU MIREA!"
```
Результат выполнения:
```text
+-----------------------+
| Hello from RTU MIREA! |
+-----------------------+
```
Для проверки написанного скрипта был использован ShellCheck:
```bash
shellcheck banner
```
В результате проверки ошибок и предупреждений обнаружено не было.
### Вывод задачи №3
В ходе выполнения задачи был создан Bash-скрипт `banner`, который принимает текст и выводит его в рамке. Размер рамки автоматически изменяется в зависимости от длины переданного текста.

## Задача №6
Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.
### Ход выполнения задачи №6
Для выполнения задачи была создана программа `check`:
```bash
#!/bin/bash
# Получение имени файла и его первой строки
file="$1"
first=$(head -n 1 "$file")
# Проверка наличия комментария в зависимости от расширения файла
if [[ "$file" == *.py ]]; then
    if [[ "$first" == \#* ]]; then
        echo "Comment exists"
    else
        echo "No comment"
    fi
elif [[ "$file" == *.c || "$file" == *.js ]]; then
    if [[ "$first" == //* ]]; then
        echo "Comment exists"
    else
        echo "No comment"
    fi
fi
```
Для предоставления программе права на выполнение была использована команда:
```bash
chmod +x check
```
Для проверки программы был создан файл `test.py`, первая строка которого содержит комментарий. После запуска:
```bash
./check test.py
```
был получен результат:
```text
Comment exists
```
Также был создан файл `test.js`, первая строка которого не содержит комментария. После запуска:
```bash
./check test.js
```
был получен результат:
```text
No comment
```
### Вывод задачи №6
В ходе выполнения задачи была создана программа `check`, которая проверяет наличие комментария в первой строке файлов с расширением `.c`, `.js` и `.py`. Работа программы была проверена на файлах с комментарием и без него.
