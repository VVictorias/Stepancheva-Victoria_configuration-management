# Результаты проверок

Команда из каталога `homework_3` в активированном окружении.

```bash
python3 -B -m unittest discover -s tests
```

**Итог:** 23 теста, `OK`. Проверки выполнены в терминале VS Code
на macOS с Python 3.14.9.

- Проверены числа, строки, имена, объявления, вложенные массивы и операции
  `+`, `-` и `ord`.
- Проверены ошибки синтаксиса, неизвестное имя, неверные аргументы
  операций, ошибки чтения и записи.
- Все три примера отдельно преобразованы через `run.sh`. Файлы
  прочитаны через `tomllib`, значения совпали с ожидаемыми.
