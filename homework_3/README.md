# Домашняя работа №3

**Вариант №22. Преобразование учебного конфигурационного языка в TOML.**

Программа читает UTF-8, разбирает конфигурацию с помощью Lark и
сохраняет значения в TOML. [Отчёт с примерами](../homework_3.md).

## Подготовка и запуск

Нужен Python 3.11 или новее. Отдельная сборка не требуется.
Окружение создаётся из корня репозитория.

```bash
cd homework_3
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

- `--input` задаёт путь к исходной конфигурации.
- `--output` задаёт путь к файлу TOML. Каталог для записи должен существовать.
- `--help` показывает справку.

Пути `--input` и `--output` обязательны. Относительные пути отсчитываются
от текущего каталога. При ошибке программа печатает сообщение в stderr
и завершает работу с ненулевым кодом.

## Примеры

Пример преобразования настроек учебного приложения.

```bash
bash run.sh --input examples/study.cfg --output /tmp/study.toml
cat /tmp/study.toml
```

В `examples` также есть конфигурации [интернет-магазина](examples/store.cfg)
и [компьютерного класса](examples/classroom.cfg). Рядом с каждой конфигурацией
лежит ожидаемый результат в TOML.

## Код и тесты

`src/language.lark` задаёт синтаксис. `src/main.py` обрабатывает параметры,
вычисляет константы и записывает TOML. Основные правила языка приведены
в [отчёте](../homework_3.md#правила-языка).

Тесты запускаются из папки `homework_3` в активированном окружении.

```bash
python3 -B -m unittest discover -s tests -q
```
