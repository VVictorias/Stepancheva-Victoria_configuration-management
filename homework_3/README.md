# Домашняя работа №3

**Вариант 22.** Перевод учебного конфигурационного языка в TOML.

Программа читает файл в UTF-8, разбирает его с помощью Lark, вычисляет
константы и записывает результат в TOML. Ход работы описан в
[отчёте](../homework_3.md).

## Подготовка и запуск

Требуется Python 3.11 или новее. Отдельная сборка не нужна.
Команды для терминала VS Code на macOS выполняются из папки `homework_3`.

```bash
cd '/Users/macbook/конфупр/homework_3'
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

В новом терминале достаточно активировать созданное окружение командой
`source .venv/bin/activate` из папки `homework_3`.

| Параметр | Назначение |
| --- | --- |
| `--input ПУТЬ` | Обязательный путь к файлу на учебном языке. |
| `--output ПУТЬ` | Обязательный путь к выходному файлу TOML. |
| `--help` | Справка по запуску. |

Пути отсчитываются от текущего каталога. Каталог для выходного файла должен
существовать. При успешном запуске программа сохраняет TOML и возвращает
код 0. Ошибка чтения, разбора, вычисления или записи даёт код 1. Ошибка в
аргументах даёт код 2.

## Синтаксис

| Конструкция | Запись |
| --- | --- |
| Целое число | `0`, `-12`, `+24`. Допустимый шаблон `[+-]?([1-9][0-9]*\|0)`. |
| Строка | `@"Текст"`. Символы между кавычками сохраняются буквально, включая обратную косую черту. |
| Массив | `list(1, @"два", list(3, 4))` или пустой `list()`. |
| Имя | `[_a-zA-Z]+`, например `_name` или `basePrice`. |
| Объявление | `10 -> base`. В TOML появляется строка `base = 10`. |
| Сложение | `?{+ base 2}`. |
| Вычитание | `?{- base 2}`. |
| Код символа | `?{ord @"A"}` даёт `65`. |

Объявления обрабатываются слева направо. Имя можно использовать после
объявления, внутри выражения. Каждому имени соответствует один ключ TOML.
Сложение и вычитание принимают два целых числа, `ord` принимает строку из
одного символа. Выражения можно вкладывать друг в друга и использовать
внутри массивов. В выходном файле целые числа должны укладываться в
знаковый 64-битный диапазон TOML.

## Примеры

| Конфигурация | Входной файл | Результат |
| --- | --- | --- |
| Учебное приложение | [study.cfg](examples/study.cfg) | [study.toml](examples/study.toml) |
| Интернет-магазин | [store.cfg](examples/store.cfg) | [store.toml](examples/store.toml) |
| Компьютерный класс | [classroom.cfg](examples/classroom.cfg) | [classroom.toml](examples/classroom.toml) |

Все три примера можно преобразовать в отдельный временный каталог.

```bash
demo="$(mktemp -d)"
for name in study store classroom; do
  bash run.sh --input "examples/$name.cfg" --output "$demo/$name.toml"
done
cat "$demo/study.toml"
```

## Демонстрация в терминале VS Code

Преобразование конфигурации компьютерного класса.

```bash
demo="$(mktemp -d)"
bash run.sh --input examples/classroom.cfg --output "$demo/classroom.toml"
cat "$demo/classroom.toml"
```

Вычисление цены со скидкой и кода символа.

```bash
bash run.sh --input examples/store.cfg --output "$demo/store.toml"
cat "$demo/store.toml"
```

Ошибка синтаксиса из-за пропущенного элемента массива.

```bash
printf '%s\n' 'list(1, ) -> items' > "$demo/bad.cfg"
bash run.sh --input "$demo/bad.cfg" --output "$demo/bad.toml"
echo $?
```

Запуск всех тестов. Тесты запускают CLI отдельным процессом и читают
выходные файлы через `tomllib`. Фактический итог приведён в
[результатах](tests/RESULTS.md).

```bash
python3 -B -m unittest discover -s tests
```
